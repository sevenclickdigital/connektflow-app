{% load common_extras i18n %}{% comment %} Reusable styled select dropdown — see the `ui_select` inclusion tag docstring. Bind `model` to a property in the enclosing x-data scope (array if `multiple`, else string). The panel is position:fixed so an overflow toolbar can't clip it. With `multiple`, an empty array means every option: all boxes show ticked, unticking one keeps the others, and ticking them all empties the array again. The last ticked box cannot be unticked, so the filter never shows nothing. Expressions that reference `model` live in Alpine DIRECTIVES (x-text / :class / @click), which resolve via the scope chain — NOT in x-data methods, whose plain JS body can't see the parent scope. {% endcomment %}
