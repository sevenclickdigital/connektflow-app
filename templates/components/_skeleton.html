The page renders at once and an element around this include fetches the slow part with HTMX (hx-trigger="load", hx-swap="outerHTML"). Only for that kind of part: a page that reads the database quickly would just flash. Optional: - variant: "cards_table" (summary cards, then a table; the default), "table" (rows only), "cards" (a grid of cards with an image), "list" (stacked rows with an avatar), "card" (one card, for a slot inside a grid). - label: the status line; defaults to "Loading…". Pass "" to hide it. - status_id: the status line's id (default "lazy-load-status"). The loading element points data-inline-error at "#", so a failed load writes its message there instead of leaving the placeholder pulsing.
