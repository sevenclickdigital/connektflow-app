Closing it is remembered per page in this browser (localStorage "cf:ideas-hero-closed:") and announced with the "ideas-hero-toggled" window event, which the lightbulb button in the page header listens to; that button sends "ideas-hero-open" to bring the card back. It never shrinks (flex-shrink-0): on a page whose content scrolls inside a flex column, as the task board's, a tall board would otherwise squeeze it. "See how it works" opens the page's YouTube video (onboarding.PageHelpVideo, set by the operator in the administrative area) in a modal; the player is only mounted while the modal is open, so closing it stops the video. A page without a video shows staff a link to add one and shows customers nothing, in a row that keeps its height either way. Expects: tab. Optional: hero_margin, the classes for the space below it (mb-6 by default; mb-0 where the page's own layout spaces it). {% endcomment %} {% page_help_video tab as help_video %}
