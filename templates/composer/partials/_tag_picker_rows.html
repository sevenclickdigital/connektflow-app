{% load i18n %} {% comment %} The list of a tag picker: each tag group as a header that applies all its tags, its tags under it, then the tags in no group. Runs inside a component that spread `window.tagGroupsBase()` (composer/partials/_tag_groups.html). Every argument is JavaScript of that component, written by the including template: query the search text selected the array of selected tag names (changed in place) toggle the function that selects or drops one tag by name on_group optional: what to run after a whole group was applied or dropped row_class optional: classes of a tag row, for a picker that has none of its own previews optional: show what a published tag will read like (`tagPreview`, `tagKindByName`) {% endcomment %}
