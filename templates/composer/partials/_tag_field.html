{% load i18n %} {% comment %} A tag field, the idea window's: the label with how many tags are picked, a box with the picked tags as chips on one line (each with its ×) and an arrow; the box opens, upwards, a list with a search (that also creates a tag), the brand's tags by group (composer/partials/_tag_picker_rows.html) and the shortcuts to create a tag, edit the tag groups and manage the saved tags. Used by the idea windows and by the task board's task windows. Runs inside an Alpine component that spread `window.tagGroupsBase()` and has `allTags`. Every argument is JavaScript of that component: selected the array of picked tag names search the search text open whether the list is open toggle the function that picks or drops one tag by name persist the function that creates a tag from the search text and picks it matches the tag names the search matches (a getter) search_ref the x-ref of the search field on_open optional: what else to run when the box is clicked new_tag optional: what "Create new tag" runs (the button shows only with it) groups optional: what "Tag groups" runs (default: openTagGroups()) Optional: name (with a name, the picked tags travel in hidden inputs of that name). {% endcomment %}
