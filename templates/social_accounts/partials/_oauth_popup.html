{% comment %} Runs a connection in a small window instead of taking the page away. A form marked ``data-oauth-popup`` is posted into a popup, with ``popup=1`` so the server ends the round trip on connect_done.html (views.finish_in_popup). That page announces, over a same-origin BroadcastChannel, where the flow continues; this page goes there, which is either itself reloaded with the new account or the account picker. A form may also carry ``data-popup-action``: the address to post to when the popup opens, for flows that take their return address in the URL (the Google sign-in on the login and signup pages). The popup is skipped, and the form submits as it always did, on touch devices and narrow screens, where a second window is more trouble than help, and when the browser blocks it. A form sent with HTMX (Mastodon's, in the connect guide, whose refusals come back inside the modal) cannot be posted into the window: the window is still opened on the click, which is when the browser allows it, and the server answers with the ``openConnectPopup`` event carrying the platform's address, which this page loads into it. Any other answer closes the window again. {% endcomment %}
