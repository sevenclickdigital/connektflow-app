{% load i18n support_tags %} {% comment %} The live chat: a small button in the bottom-right corner of every page and the conversation panel it opens. Drawn only for a customer in their own account ({% support_chat %}). The conversation lives on the server (support.Chat), so it carries on from page to page: each page asks for it again and, while a chat is open, polls every few seconds (only while the tab is visible) and reports the page it is on to the team (``chat/visit/``; never shown back to the visitor). The panel's open or closed state is kept for the tab in sessionStorage. With nobody on the team's console, the first message becomes a ticket (services.visitor_writes) and the panel says so. The "support-chat-open" window event opens the panel from elsewhere (the help centre). "End" asks first and then minimises the panel; past chats are in My conversations (support:chats). Every user-visible text is translated here and handed over in #support-chat-strings; messages are escaped and only their formatting marks become tags (support/partials/_message_format.html). {% endcomment %} {% support_chat as chat %} {% if chat is not None %}
