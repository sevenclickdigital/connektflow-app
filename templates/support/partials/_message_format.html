{% comment %} The support messages' formatting, as in WhatsApp: *bold*, _italic_, ~strike~, `code`; web addresses become links. window.cfMessageFormat: - render(text): the text escaped, then the marks as those few tags (for x-html); - wrap(textarea, mark): puts the mark around the selection, or the cursor, with the browser's undo history (execCommand insertText), adding the space a mark needs where it would stick to a letter; - keydown(event, textarea): Ctrl/⌘+B and Ctrl/⌘+I. Mirrors the Python filter support_tags.message_format: change both together. Included by the chat widget and the team's console and ticket screens; it defines itself once. {% endcomment %}
