{% load i18n %} {% comment %} The art request's channels and formats. On the left the workspace's networks, one row each (connected ones first, the account in the row's tooltip; then the others): the row shows that network's formats. On the right the shown network's formats as cards in two rows, scrolled sideways with the arrows, each with its glyph, size and proportion, and under them "Select all", which ticks or unticks every format of the shown network (half ticked when only some are). They post as "formats". Runs inside an Alpine component that spread artPicker() (static/js/task-window.js): ``tab`` is the network shown, ``counts`` / ``totals`` the ticked and offered formats per network (the header reads the shown one's: "2 of 5"), ``toggleNetwork(key)`` ticks a whole network (the "Select all" box). Used by the art request form and by the task board's new task window. Expects: groups (tasks.views._art_catalogue), selected (format keys ticked); optional locked (format keys ticked and fixed: a task's arts already asked for, which don't post again). {% endcomment %}
