{% load i18n %} {% comment %} "Create new item": how anything is created on the task board, in two steps. First a small window offers the two kinds; picking one turns it into that kind's form (with "Back" to the choice): - Task: on the left title, description, column, priority, due date (today by default), assignees and tags (the brand's tag list, shared with ideas); on the right its named checklists, each with a title and items. Posted to tasks:task_create, whose taskCreated closes it. - Art request: the art request form (tasks/partials/_request_arts_form.html), fetched the first time the kind is picked; it creates the task and opens it on the board itself. Opened with $dispatch('open-new-item', { column: '' }) by a column's "Add task", on the choice for that column (kind: 'art' goes straight to the art request form). The script is newItemForm() in tasks/board.html. Expects: columns, priorities, members, today, workspace (the page renders the tag suggestions). {% endcomment %}
